# frontend-pedidos360 (Angular)

Pendiente de scaffolding en la **Fase 6** del plan.

- Framework objetivo: **Angular 18+** con **MSAL Angular** (login Azure AD / Entra External ID).
- Autorización por rol: `Admin`, `Operador`, `Cliente` (guards).
- Pantallas: `/login`, `/dashboard`, `/orders`, `/catalog`, `/reports`, `/audit`.
- Consumo del backend adjuntando `Authorization: Bearer <access_token>`.

> Assets de marca reutilizables (del antiguo Grupo Cordillera) preservados en `../brand/`.
